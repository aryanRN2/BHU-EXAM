# Project AGENTS Instructions & Rules

## Mandatory PYQ Verification & Audit Rules

When verifying, searching, digitizing, or reporting on PYQs (Previous Year Questions) in this workspace:

1. **Page-by-Page Multi-Paper PDF Scan**: Always scan every page of a PDF file. Never assume a single PDF file contains only one paper.
2. **Academic Year Strict Matching**: Always verify the exact Academic Session/Year (e.g., 2024-25 vs 2025-26). Never mark a 2025-26 paper as added simply because a 2024-25 paper with the same course code exists.
3. **Exam Type & Term Verification**: Distinguish between Mid-Term, End-Term, and Sessional examinations.
4. **Course & Department Verification**: Verify Subject Name, Course Code (e.g., `COMMD11`, `COMMD21`, `ESMN111`, `CIMSE11`), NEP Stream (MDC, SEC, VAC, Major, Minor), and Faculty/Department.
5. **Database Cross-Referencing**: Verify matching against both `js/nep-data.js` and `aaa/ALL_PYQS_LATEX/`.

For complete documentation of these audit protocols, refer to [PYQ_CHECK_RULES.md](file:///Users/aryanmaurya/exam%20portal/PYQ_CHECK_RULES.md).
