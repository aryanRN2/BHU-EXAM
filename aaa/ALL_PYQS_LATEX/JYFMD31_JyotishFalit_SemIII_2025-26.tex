\bigskip


\begin{enumerate}[label=   \textbf{\arabic*.}]
    \item Give a general introduction to Jyotish Shastra.

    \item Write an introduction to the concepts of Paksha, Masa, Ritu, Ayana, and Varsha from an astrological perspective.

    \item What is Ishtakala? Write with suitable examples. If the sunrise on 12/10/2025 is at 06:15 AM, calculate the Ishtakala for the following birth times:
    
\begin{enumerate}[label=(\alph*)]
        \item Birth time: 12/10/2025, 10:20 AM
        \item Birth time: 12/10/2025, 5:35 PM
        \item Birth time: 12/10/2025, 2:26 AM
    \end{enumerate}

    \item What is Chalan? Write with examples.

    \item Explain the method for deriving Swodayamana from Lankodayamana.

    \item Explain the method of Lagna Sadhana with a self-assumed (hypothetical) example.

    \item Write the method of calculating Vimshottari Dasha with an example.

    \item What is Panchanga? Give an introduction to its five components.
\end{enumerate}
