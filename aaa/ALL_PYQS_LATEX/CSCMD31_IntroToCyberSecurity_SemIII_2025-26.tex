\begin{enumerate}[label=\textbf{\arabic*.},leftmargin=*,itemsep=12pt]

  \item \textbf{Objective Type Questions:}\pts{7 $\times$ 2 = 14}
  \begin{parts}
    \item What is the most suitable definition of Cyber Security?
      \begin{parts}
        \item The practice of only protecting computer hardware from physical damage.
        \item Using cryptography to secure online banking transactions.
        \item Protecting digital systems, networks, programs, and data from attacks, damage, or unauthorized access.
        \item The process of developing anti-virus software.
      \end{parts}

    \item Which term in the CIA Triad ensures that information is accurate and unaltered?
      \begin{parts}
        \item Confidentiality
        \item Integrity
        \item Availability
        \item Authentication
      \end{parts}

    \item Which type of malware is a standalone program that is self-replicating and spreads automatically across networks by exploiting system vulnerabilities without requiring human intervention?
      \begin{parts}
        \item Virus
        \item Trojan
        \item Worm
        \item Spyware
      \end{parts}

    \item What is the primary function of Ransomware?
      \begin{parts}
        \item To secretly record every keystroke made on the infected system.
        \item To disguise itself as legitimate software to create a backdoor for attackers.
        \item To encrypt a victim's files, making them inaccessible until a ransom is paid.
        \item To continuously monitor user activity and relay personal information to an attacker.
      \end{parts}

    \item What is the term for a scam attack that uses fraudulent voice calls to manipulate a victim into giving up sensitive information?
      \begin{parts}
        \item Phishing
        \item Smishing
        \item Baiting
        \item Vishing
      \end{parts}

    \item Which type of attack involves a single source flooding a target server with traffic until it is overwhelmed and cannot serve legitimate users?
      \begin{parts}
        \item Malware
        \item MitM (Man-in-the-Middle)
        \item DoS (Denial-of-Service)
        \item Business Email Compromise (BEC)
      \end{parts}

    \item Which of the following is defined as a weakness in a system or process that a threat could potentially exploit?
      \begin{parts}
        \item Asset
        \item Risk
        \item Task
        \item Vulnerability
      \end{parts}
  \end{parts}

  \item Define Cyberspace and Cyber Crime? List and explain the key criteria to choose a web browser.\pts{14}

  \item Discuss the guidelines for setting a secure password. What is Two-step authentication? How can a Password Manager be useful to manage passwords?\pts{14}

  \item Write the best-practice guidelines for safer social media. Do you agree that Smartphone Security is very crucial in Cyber-security? How will you protect your smartphone devices from attack landscapes?\pts{14}

  \item What is IT Act 2000? List the various sections of this act related to Cyber Security and discuss any one section with its sub-section in brief.\pts{14}

  \item Discuss Cyber Security Assurance. What do you understand by Vulnerability Assessment and Penetration Testing? What are the key challenges in Cyber Security Assurance to achieve? Explain in brief.\pts{14}

  \item Compare any \textbf{two} of the following terminologies:\pts{2 $\times$ 7 = 14}
  \begin{parts}
    \item Confidentiality and Integrity
    \item Online Banking and Mobile Banking
    \item Ethics and Policies of Computer
    \item Section 70 and Section 66 of IT Act
  \end{parts}

\end{enumerate}
