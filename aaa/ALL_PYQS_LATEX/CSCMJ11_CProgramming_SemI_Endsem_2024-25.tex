\noindent\textbf{Question 1} \textit{(Compulsory --- Attempt any nine)}\pts{$9 \times 2 = 18$}
\begin{parts}
  \item Differentiate between \texttt{int} and \texttt{float} data types.
  \item List the rules for naming a variable in C.
  \item What is the role of \texttt{continue} keyword in C programming?
  \item Is it possible to rename a data type in C? If yes, then how?
  \item What is the use of \texttt{sizeof()} in C programming?
  \item What is the difference between \texttt{scanf()} and \texttt{fscanf()} functions?
  \item Write the syntax and usage of ternary operator in C.
  \item Write the syntax of \texttt{main()} function while using command line arguments.
  \item What will be the output of the following code? (Explain with reason)
\begin{lstlisting}
void main() {
    int a = 3, b = 4;
    b %= 3 + 4;
    a *= a + 5;
    printf("%d %d", b, a);
}
\end{lstlisting}
  \item What will be the output of the following code? (Explain with reason)
\begin{lstlisting}
void main() {
    int a[] = {10, 20, 30, 40, 50};
    int *p;
    p = a;
    printf("%d ", *p);
    p += 2;
    printf("%d ", *p);
}
\end{lstlisting}
\end{parts}
