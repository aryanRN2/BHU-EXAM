\noindent\textbf{Q1.} Let $X \sim \mathcal{N}(\mu = 50, \sigma^2 = 25)$. A random sample of size $n = 25$ is drawn from this distribution, and the experiment is repeated independently 30 times.

Define the estimators:
\[
T_1 = \bar{X}, \quad T_2 = \frac{X_1 + X_2 + X_3}{3}, \quad T_3 = \frac{X_1 + X_2 + \dots + X_{10}}{10}
\]

\begin{parts}
  \item Compute all estimators.
  \item Show that all estimators are unbiased.
  \item Compute the variance of each estimator.
  \item Among all given estimators, which estimator is efficient estimator.
\end{parts}

\medskip\rule{\linewidth}{0.2pt}\medskip

\noindent\textbf{Q2.} A sample of size $n = 25$ is drawn from a normal population to study daily electricity consumption (in kWh). The sample mean is $\bar{x} = 18.5$ and the sample standard deviation is $s = 3.2$.

\begin{parts}
  \item Construct confidence intervals for the population mean at 70\%, 80\%, 90\%, and 95\% levels.
  \item Interpret each confidence interval in context.
  \item Compute the length of each confidence interval.
  \item Plot the relationship between confidence level and interval length.
  \item Comment on how the interval length changes with confidence level.
\end{parts}
