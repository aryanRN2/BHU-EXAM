\begin{parts}
  \item What do you mean by a one-to-many relationship?
  
\begin{parts}
    \item One class may have many teachers.
    \item One teacher can have many classes.
    \item Many classes may have many teachers.
    \item Many teachers may have many classes.
  \end{parts}

  \item A Database Management System is a type of \_\_\_\_\_\_\_\_ software.
  
\begin{parts}
    \item System software.
    \item Application software.
    \item General software.
    \item Both (a) and (c).
  \end{parts}

  \item Which of the following refers to the level of data abstraction that describes exactly how the data is actually stored?
  
\begin{parts}
    \item Conceptual Level.
    \item Physical Level.
    \item File Level.
    \item Logical Level.
  \end{parts}

  \item Which one of the following is a type of Data Manipulation Command?
  
\begin{parts}
    \item Create.
    \item Alter.
    \item Delete.
    \item All of the above.
  \end{parts}

  \item The term ``Data independence'' refers to:
  
\begin{parts}
    \item Data is defined separately and not included in the programs.
    \item Programs are not dependent on the logical attributes of the data.
    \item Programs are not dependent on the physical attributes of the data.
    \item Both (b) and (c).
  \end{parts}

  \item What is the relational calculus?
  
\begin{parts}
    \item It is a kind of procedural language.
    \item It is a non-procedural language.
    \item It is a high-level language.
    \item It is a Data Definition language.
  \end{parts}

  \item Which one of the following refers to the total view of the database content?
  
\begin{parts}
    \item Conceptual view.
    \item Physical view.
    \item Internal view.
    \item External view.
  \end{parts}

  \item The Database Management Query language is generally designed to:
  
\begin{parts}
    \item Support end-users who use English-like commands.
    \item Specifying the structure of the database.
    \item Support in the development of complex application software.
    \item All of the above.
  \end{parts}

  \item Which one of the following is commonly used to define the overall design of the database?
  
\begin{parts}
    \item Application program.
    \item Data definition language.
    \item Schema.
    \item Source code.
  \end{parts}

  \item Which of the following keys is generally used to represent the relationships between the tables?
  
\begin{parts}
    \item Primary key.
    \item Foreign key.
    \item Secondary key.
    \item None of the above.
  \end{parts}
