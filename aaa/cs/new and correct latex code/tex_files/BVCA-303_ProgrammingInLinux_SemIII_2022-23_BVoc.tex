\bigskip\noindent{\large\bfseries SECTION --- A: Long Answer Questions}\pts{$15 \times 2 = 30$}
\rule{\linewidth}{0.4pt}\smallskip

\noindent\textit{Instructions: Long answer type questions to be answered in about 750 words each.}

\medskip\noindent\textbf{Question 1.}
\begin{parts}
  \item What is an Operating System? Explain the Linux Operating System architecture and list its key features.
  \item What are \texttt{inode} and \texttt{dentry} in the context of the Linux file system? Describe the Linux file system structure in detail.
\end{parts}
\centerline{\textbf{OR}}

\medskip\noindent\textbf{Question 2.}
\begin{parts}
  \item What is octal permission notation? Discuss the Linux file permission model with suitable examples.
  \item What is context switching? Explain the various states of a Linux process in detail.
\end{parts}

\bigskip\noindent{\large\bfseries SECTION --- B: Short Answer Questions}\pts{$5 \times 6 = 30$}
\rule{\linewidth}{0.4pt}\smallskip

\noindent\textit{Instructions: Attempt any six questions. Short answer type questions to be answered in about 550 words each.}

\medskip\noindent\textbf{Question 3.} Write a shell program to calculate the average and sum of a given set of numbers.

\medskip\noindent\textbf{Question 4.} Write a shell program to compute the factorial of a given number.

\medskip\noindent\textbf{Question 5.} List and describe the different modes of the \texttt{vi} editor.

\medskip\noindent\textbf{Question 6.} Explain the working and usage of the \texttt{awk} utility with suitable examples.

\medskip\noindent\textbf{Question 7.} Explain what background processes are and how they are managed in Linux.

\medskip\noindent\textbf{Question 8.} Discuss any five essential Linux commands with examples.

\medskip\noindent\textbf{Question 9.} Write a brief note on the Linux shell and its different types.

\medskip\noindent\textbf{Question 10.} Discuss briefly the Dash, Activities, and Grid GUI elements in Ubuntu Linux.

\bigskip\noindent{\large\bfseries SECTION --- C: Very Short Answer Questions}\pts{$10 \times 1 = 10$}
\rule{\linewidth}{0.4pt}\smallskip

\noindent\textit{Instructions: Answer the following questions in a single word or sentence.}

\begin{enumerate}[label=\arabic*.,leftmargin=*,itemsep=6pt]
  \item What is the command used to display the MAC address of a Linux machine?
  \item Which command is used to rename a file in Linux?
  \item Write the command used to print a file from the terminal.
  \item In which system file are user passwords saved in Linux?
  \item What option of \texttt{grep} enables us to ignore the case of alphabetical characters?
  \item Name the boot loader commonly used in Ubuntu Linux.
  \item Which command is used to search forward in the \texttt{vi} editor?
  \item Name the processes that run unattended in the background.
  \item What key combination will terminate a running command in the terminal?
  \item Name the software that runs the GUI environment in Ubuntu Linux.
\end{enumerate}
