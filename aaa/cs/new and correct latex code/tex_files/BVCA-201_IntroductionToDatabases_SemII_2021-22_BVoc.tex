\begin{parts}

    \item Database schema
    \item Client/server architecture
    \item Owner entity type
    \item Weak entity type
    \item Entity
    \item Attribute value
    \item Relation state
    \item Degree of a relation
    \item Normalization
  \end{parts}

\noindent {\large\bfseries PART --- B}

\rule{\linewidth}{0.4pt}\smallskip




\noindent   \textbf{Medium Answer Questions} (Attempt all questions; either/or type)\pts{5 $ \times$ 4 = 20}

\begin{enumerate}[label=\arabic*.,leftmargin=*,itemsep=12pt]
  \setcounter{enumi}{1}
  \item What is the difference between logical data independence and physical data independence? Which one is harder to achieve, and why?
  
\begin{center}   \textbf{OR}\end{center}
  Discuss the different data types supported in SQL.
  \item Discuss the entity integrity and referential integrity constraints. Why is each considered important?
  
\begin{center}   \textbf{OR}\end{center}
  Discuss Functional Dependency with a suitable illustrative example.
  \item What is a relationship type? Explain the differences among a relationship instance, a relationship type, and a relationship set.
  
\begin{center}   \textbf{OR}\end{center}
  What is a participation role? When is it necessary to use role names in the description of relationship types?
  \item What is meant by a recursive relationship type? Give some examples of recursive relationship types.
  
\begin{center}   \textbf{OR}\end{center}
  What is SQL? Write down the syntax to create a table and insert records into a table.
  \item Why are duplicate tuples not allowed in a relation?
  
\begin{center}   \textbf{OR}\end{center}
  What is the difference between a key and a super key?
\end{enumerate}
