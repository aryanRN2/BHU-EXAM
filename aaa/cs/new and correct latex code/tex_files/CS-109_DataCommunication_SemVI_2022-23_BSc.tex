\medskip


\noindent   \textbf{Question 1.} Write a short note on any four of the following techniques/protocols: \pts{3.5 $ \times$ 4 = 14}

\begin{parts}
  \item Amplitude Modulation (AM)
  \item Frequency-Division Multiplexing (FDM)
  \item Delta Modulation (DM)
  \item Cyclic Redundancy Check (CRC)
  \item High-Level Data Link Control (HDLC)
  \item Direct Sequence Spread Spectrum (DSSS)
\end{parts}

\medskip


\noindent   \textbf{Question 2.}

\begin{parts}
  \item What is wireless (unguided) transmission media? What are the three major types of wireless transmission media? Describe each in detail.\pts{6}
  \item What are circuit-switched and packet-switched networks? Discuss the differences between them.\pts{8}
\end{parts}

\medskip


\noindent   \textbf{Question 3.}

\begin{parts}
  \item What is the result of scrambling the sequence $11100000000000$ using the following scrambling techniques? Assume that the last non-zero signal level has been positive:\pts{6}
  
\begin{parts}
    \item B8ZS
    \item HDB3 (assume the number of non-zero pulses is odd after the last substitution)
  \end{parts}
  \item What is the purpose of the Pulse Code Modulation (PCM) technique? Describe the components of a PCM encoder with an example.\pts{8}
\end{parts}

\medskip


\noindent   \textbf{Question 4.}

\begin{parts}
  \item Describe the following mechanisms for modulating digital data into an analog signal with examples: Amplitude Shift Keying (ASK), Frequency Shift Keying (FSK), Phase Shift Keying (PSK), and Quadrature Amplitude Modulation (QAM).\pts{6}
  \item Station A needs to send a message consisting of 9 packets to Station B using a sliding window (window size 3) and Go-Back-N error control strategy. All packets are ready and immediately available for transmission. If every 5th packet that A transmits gets lost (but no ACKs from B ever get lost), then what is the total number of packets that A will transmit for sending the message to B? Explain with a diagram.\pts{8}
\end{parts}

\medskip


\noindent   \textbf{Question 5.}

\begin{parts}
  \item Discuss Frequency Hopping Spread Spectrum (FHSS) with a suitable diagram.\pts{6}
  \item A sender needs to send the four data items given in hexadecimal:   \texttt{3456},   \texttt{ABCC},   \texttt{02BC}, and   \texttt{EEEE}. Answer the following questions:\pts{8}
  
\begin{parts}
    \item Calculate the checksum at the sender site.
    \item Calculate the checksum at the receiver site if the second data item is changed to   \texttt{ABCE}.
    \item Find the checksum at the receiver site if the second data item is changed to   \texttt{ABCE} and the third data item is changed to   \texttt{02BA}.
  \end{parts}
\end{parts}

\medskip


\noindent   \textbf{Question 6.}

\begin{parts}
  \item What is data link control? Describe the key components of data link control.\pts{6}
  \item Why do we need flow and error control? Discuss the stop-and-wait flow control technique with an example.\pts{8}
\end{parts}
