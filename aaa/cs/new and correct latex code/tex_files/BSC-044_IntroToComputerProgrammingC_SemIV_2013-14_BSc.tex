\medskip\noindent\textbf{Question 1.} Answer any six questions: \pts{$3\times6=18$}
\begin{parts}
  \item What are the steps involved in solving problems using computer?
  \item What are logical operators? List them with their meaning.
  \item What is the difference between \texttt{scanf()} and \texttt{printf()}?
  \item What is bottom up approach of program designing?
  \item Define data type. Write the names of any three data types.
  \item What is a header file? Write the names of any three header files.
  \item What is the difference between local and global variables?
\end{parts}

\medskip\noindent\textbf{Question 2.}
\begin{parts}
  \item What is an algorithm? Draw the flow chart for comparing three given numbers and display the largest number. \pts{5}
  \item What are the advantages of High level languages over Machine level languages? Write the names of any three high level languages. \pts{3}
  \item What are the differences between Compiler and Interpreter? \pts{3}
\end{parts}

\medskip\noindent\textbf{Question 3.}
\begin{parts}
  \item Explain the various decision making statements in C language with an example for each. \pts{6}
  \item Explain the difference between a `while` loop and a `do-while` loop with a suitable example. \pts{6}
\end{parts}

\medskip\noindent\textbf{Question 4.}
\begin{parts}
  \item Discuss about the precedence of operators in C. What will be the output of the following program: \pts{4}
\begin{lstlisting}[language=C]
void main()
{
    int x;
    x = -3 + 4 - 7 * 8 / 5 % 10;
    printf("x = %d\n", x);
}
\end{lstlisting}
  \item What is an array? How do you declare and initialize a one dimensional array? Illustrate with an example. \pts{5}
  \item Write a `C` program to convert the given temperature in Fahrenheit to Celsius. \pts{4}
\end{parts}

\medskip\noindent\textbf{Question 5.}
\begin{parts}
  \item Define pointer. What are the advantages of using pointers? \pts{4}
  \item What is the difference between a String and Array of characters? \pts{3}
  \item Explain any three String handling library functions in `C` with an example for each. \pts{6}
\end{parts}

\medskip\noindent\textbf{Question 6.}
\begin{parts}
  \item Define Function in C language. What is the difference between a user defined function and library function? \pts{4}
  \item Explain the parameter passing techniques of functions through an example. \pts{6}
  \item What do you mean by function prototype? \pts{3}
\end{parts}

\medskip\noindent\textbf{Question 7.}
\begin{parts}
  \item Define storage classes in C Programming. List various storage classes used in `C` with their properties. \pts{6}
  \item What is a structure? How do you declare a structure variable and access its members? Explain with an example. \pts{7}
\end{parts}
