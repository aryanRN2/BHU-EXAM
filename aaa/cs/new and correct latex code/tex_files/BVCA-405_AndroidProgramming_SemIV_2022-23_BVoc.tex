\noindent   \textbf{Question 2.} Write a Flutter code snippet to create a simple application with a single page containing a centered ``Hello, Flutter!'' text. Also explain the concept of state management in Flutter and discuss the different approaches, providing examples of when to use each.

\medskip



\noindent   \textbf{Question 3.} Write the Flutter code to build an application with the following specifications:

\begin{parts}
  \item The first page of the application should have an AppBar with the text ``Flutter App''.
  \item The first page should have a body with the text ``First Page'' and an image from the assets folder named ``flutter.jpg''.
  \item The application should have a floating action button at the bottom of the screen which navigates to the second page.
  \item The second page should contain an AppBar with the text ``Second Page'' and a back button that returns to the homepage.
  \item The second page should have a body with the text ``Second Page'' and an image from the assets folder named ``second.jpg''.
\end{parts}

\medskip

\noindent   \textbf{Question 5.} Attempt any six parts (Answer in about 200 words each): \hfill   \textbf{6 $ \times$ 6 = 36 Marks}

\begin{parts}
  \item What is the   \texttt{AndroidManifest.xml} file? Write down its purpose and list its key components.
  \item What is an APK file? Discuss in detail how you can build an APK file in Flutter.
  \item Discuss the directory structure of a standard Android project.
  \item What is the use of the   \texttt{ListView.builder} widget in Flutter? Explain its different components using an example.
  \item What are the key differences between Dalvik Virtual Machine (DVM) and Android Runtime (ART)?
  \item What is Flutter? Write down some of the main disadvantages of using the Flutter framework.
  \item What is the purpose of the   \texttt{pubspec.yaml} file in a Flutter project? Explain the process of adding external dependencies (packages) using this file with an example.
  \item Discuss the importance of using   \texttt{async} and   \texttt{await} in Flutter when working with asynchronous operations. Provide a code example.
  \item Write a Flutter Dart code snippet to create a simple app that displays a list of items with images and text. Include the widget tree, data source, and any relevant packages.
\end{parts}
